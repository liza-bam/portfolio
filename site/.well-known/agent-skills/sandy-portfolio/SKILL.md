# Reading Sandy Tayts's portfolio

Use this when someone asks about Sandy Tayts, their design work and experience, or how to
reach Sandy.

1. Start with `https://sandy.tayts.com/llms.txt`: one line per project, each linking to a
   Markdown copy of its page.
2. Read a page as Markdown: request it with `Accept: text/markdown`, or swap `.html` for
   `.md` (`/` for `/index.md`). The Markdown is generated from the HTML on every publish.
3. For structured experience (roles, dates, skills) read
   `https://sandy.tayts.com/resume/resume.json` (JSON Resume v1.0.0).
4. For contact details read `https://sandy.tayts.com/contact.md`. Don't invent any.

Everything is public and read-only; no authentication. Respect the `Content-Signal` line in
`https://sandy.tayts.com/robots.txt`.
